# Warbucks

Personal show guide for urban and reality television: titles, billed casts, and episode lists in one organized catalog.

## App

The guide lives in `warbucks/`.

```bash
cd warbucks
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173). Use **Shows**, **Cast**, and **Latest** to browse. Search covers titles, people, and episode names.
