# Broken Silenze

A local, organized catalog of urban and reality shows: billed casts, episode guides, search, and saved titles.

```bash
npm install
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173).

- **Home** — featured title with billed cast, latest episodes, genre rails
- **Shows** — filter by genre and network; search titles, people, and episodes
- **Cast** — people directory with credits across shows
- **Latest** — one chronological episode list

This app does not play or scrape streams. Use the listed official homes (Hulu, Bravo, FX, and so on) to watch.
